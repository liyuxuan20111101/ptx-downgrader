# M0 可行性尖刺

**目的**:证明"降级后的 PTX → 驱动 JIT → sm_61 硬件正确执行"这条环路通,
且 fp16 与 int8 两条降级目标路径(Pascal 最重要的两类算力)数值正确。

**零改动承诺**:本阶段不升级驱动、不装任何工具链。驱动 472.12 自带的 JIT
(对应 CUDA 11.4,PTX ISA 7.0)就是我们依赖的机制本身——用它验证,即是在
测试项目最终赖以生存的路径。

## 三个 kernel

| 文件 | 模拟的降级场景 | 验证点 |
|---|---|---|
| `ptx/vec_add.ptx` | 最小环路:加载→启动→回读 | 流水线本身 |
| `ptx/half_scale.ptx` | 新架构 fp16 矩阵指令(mma)→ Pascal 的 f16 FMA 展开 | fp16 路径数值正确 |
| `ptx/dp4a_dot.ptx` | 新架构张量/int8 指令 → sm_61 原生 dp4a | int8 量化推理的基石 |

## 运行

```
python runner.py
```

预期输出:三个 kernel 各自 PASS(与 numpy 参考实现逐位/容差比对)+ 简单耗时。
